# MAP Adaptive Systems

The adaptive-systems section owns the use of Extension Schemas for observation,
usage capture, personalization, adaptive evolution, and supporting background
activity.

Extension Schemas may extend MAP Core schemas or schemas owned by other
extenders. Universal extension, dependency, ownership, and compatibility rules
belong to the type system; this section owns how adaptive systems use those
capabilities without flattening their cross-schema nature.

The documents in this section preserve the existing adaptive-system concepts
while the broader documentation refactor establishes their long-term
boundaries. See the [document role manifest](../document-role-manifest.md) for
ownership and authority rules.
