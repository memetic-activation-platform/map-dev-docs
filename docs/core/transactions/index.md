# MAP Transactions

The transactions section owns transaction lifecycle, staging, commit, rollback,
recovery, relationship occurrence persistence, and transaction-owned schema
concepts.

General storage contracts remain with storage, while universal descriptor and
schema semantics remain with the type system. See the
[document role manifest](../document-role-manifest.md) for the governing
boundaries.

## Documents

- [Relationship Occurrence Persistence Design Spec](relationship-persistence-design-spec.md)
  is the WIP home for forward/inverse commit outcomes, pending remote
  completion, retry, and repair semantics.
